Hermes Inbox

A private, personal Gmail integration operated by the owner of the GitHub account giveme11us. It helps its owner search, read and summarize their own email using their personal Hermes assistant. It is not a public sign-up service and is not affiliated with Google or Nous Research.

Privacy notice

Updated 16 October 2026. The existing reader uses the Google Gmail API gmail.readonly permission to access message headers, message content, labels and other email information without modifying the mailbox.

Optional organization access requests a separate gmail.modify authorization, one account at a time. After the owner's consent and verification of identity and granted scope, the organization tool can archive and unarchive messages, apply or remove existing labels, move messages using those labels, move messages to Trash and restore them from Trash. The tool does not create labels; new labels are created by the owner in Gmail.

The Google permission is broader than these features: gmail.modify also permits composing and sending email. The tool blocks sending email, creating or sending drafts, and permanent deletion through a default-deny allowlist of HTTP methods and API endpoints. This is a code-level restriction, not a narrower Google scope or a sandbox: another program with the token could exercise the broader permission. No permanent-deletion endpoints are used. Messages moved to Trash remain subject to Gmail's own retention and automatic deletion rules. Organization actions generate private audit logs that may contain message identifiers and action results.

Access is used for the owner's requested email assistance and private agent workflows. Message data and derived summaries may be processed on the owner's private infrastructure and by the AI service providers configured for the assistant. This is not a promise of exclusively on-device processing. Relevant outputs may remain in private conversation history, reports, memory or backups until the owner deletes them under the applicable storage and provider policies.

OAuth credentials are stored in access-restricted files on the owner's infrastructure. Credentials and mailbox contents are not published on this website or in its repository. This site contains no email login form, analytics scripts or advertising; GitHub Pages may process visitor connection data according to GitHub's privacy statement.

Google user data is not sold, used for advertising or intentionally used to train generalized AI models. Access and transfers are limited to providing the owner's email-assistance features, subject to the Google API Services User Data Policy, including its Limited Use requirements.

The owner can stop using the organization tool separately from the reader; its token is stored separately with owner-only (0600) permissions. The owner can revoke access at any time through Google Account connections. Google-side revocation may affect all permissions for this app, including the existing reader. Revocation stops future authorized access but does not automatically erase previously generated summaries, audit logs or backups; those must be removed from their respective stores. For questions, contact the operator through the GitHub profile. Do not post private email data publicly.
